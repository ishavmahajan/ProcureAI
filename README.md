# ProcureAI

ProcureAI is an AI-assisted procurement application that will help users compare supplier quotes and make more informed purchasing decisions.

## Project Goal

Procurement teams often compare supplier information manually across documents and spreadsheets. ProcureAI aims to organize this information, compare costs, identify important differences, and explain its recommendations.

## Planned Features

- Import supplier quote data
- Compare prices and total costs
- Evaluate suppliers using multiple criteria
- Generate AI-assisted procurement recommendations
- Explain why a supplier was recommended
- Present results through a simple user interface

## Technology Stack

- Python
- Git and GitHub
- Additional AI and web technologies will be added as the project develops
